# English Cardbook

Личное приложение для изучения английского языка.

Идея не в том, чтобы заменить существующие платформы, а в том, чтобы создать
пространство, полностью адаптированное под собственный способ обучения:
свой словарь, свои колоды, свой журнал занятий с репетитором и свои конспекты
по грамматике — в одном месте и без лишнего.

## Возможности

**Словарь.** Слова с переводом, комментарием «откуда я узнала это слово»
(YouTube, книга, репетитор, сериал), избранным и поиском.

**Колоды.** Объединение слов по темам — «Фрукты», «Программирование»,
«Путешествия». Колода собирается галочками на странице со всеми словами.
Одно слово может входить сразу в несколько колод.

**Карточки.** Режим обучения: случайная карточка из выбранной колоды,
кнопка «Следующая карточка».

**История занятий.** Журнал уроков: дата, преподаватель, продолжительность,
пройденные темы и заметки.

**Грамматика.** Собственная база конспектов — отдельная страница на каждую тему
со свободным редактированием.

**Оформление.** Две темы — Soft Pink и Soft Gray. Интерфейс на русском и английском.

## Технологии

- React 19 + TypeScript
- Vite
- React Router
- localStorage — данные хранятся локально в браузере

## Запуск

```bash
npm install
npm run dev
```

Сборка production-версии:

```bash
npm run build
```
