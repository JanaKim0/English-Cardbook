# English Cardbook

Личное приложение для изучения английского языка.

Идея не в том, чтобы заменить существующие платформы, а в том, чтобы создать
пространство, полностью адаптированное под собственный способ обучения:
свой словарь, свои колоды, свой журнал занятий с репетитором и свои конспекты
по грамматике — в одном месте и без лишнего.

## Возможности

**Словарь.** Слова и целые фразы с переводом и комментарием «откуда я узнала
это слово» — YouTube, книга, репетитор, сериал. Избранное со звёздочкой,
поиск по слову, переводу и источнику. Если добавить слово, которое уже есть,
приложение подскажет — но сохранить всё равно позволит: у слова может быть
несколько значений.

**Колоды.** Объединение слов по темам — «Фрукты», «Программирование»,
«Путешествия». Колода собирается галочками на странице со всеми словами.
Одно слово может входить сразу в несколько колод, и рядом с ним в словаре
неброско видно, в какие именно.

**Обучение.** Два режима. Карточки: случайное слово из выбранной колоды,
переворот по клику, кнопка «Следующая карточка». Слова идут вперемешку,
но каждое по разу за круг. Тест: выбор правильного перевода из четырёх
вариантов и результат в конце.

**История занятий.** Журнал уроков: дата, преподаватель, продолжительность,
пройденные темы и заметки. Поиск по всему журналу.

**Грамматика.** Собственная база конспектов — отдельная страница на каждую тему
со свободным редактированием: заголовки, списки, жирный шрифт и курсив.
Правки сохраняются сами.

**Статистика.** Сколько накоплено слов, колод, занятий и конспектов, сколько
всего часов уроков и откуда взялись слова.

**Резервная копия.** Все данные выгружаются в один файл и загружаются обратно.

**Оформление.** Две темы — Soft Pink и Soft Gray. Интерфейс на русском
и английском.

## Технологии

- React 19 + TypeScript
- Vite
- React Router
- localStorage — данные хранятся локально, без сервера и регистрации
- Tauri — упаковка в десктопное приложение для Windows

## Запуск

В браузере:

```bash
npm install
npm run dev
```

Как настольное приложение, в отдельном окне:

```bash
npm run app
```

## Сборка

Веб-версия:

```bash
npm run build
```

Установщик и `.exe` для Windows:

```bash
npm run app:build
```

Готовые файлы появятся в `src-tauri/target/release/bundle/`:
установщик `.exe` в папке `nsis` и пакет `.msi` в папке `msi`.
После установки приложение открывается в своём окне и ярлыком с рабочего стола,
интернет ему не нужен.

Для сборки десктопной версии нужны [Rust](https://rustup.rs/)
и Microsoft C++ Build Tools; сама веб-версия собирается без них.

Иконка приложения собирается из `app-icon.png` командой `npx tauri icon app-icon.png`.

Важно: после смены иконки обычная пересборка её не подхватит — Cargo не считает
замену файла иконки поводом заново встраивать ресурсы Windows. Нужно удалить
отпечатки сборки и собрать заново:

```bash
rm -rf src-tauri/target/release/build/english-cardbook-* src-tauri/target/release/.fingerprint/english-cardbook-*
npm run app:build
```

## Где хранятся данные

Всё лежит в localStorage браузера под ключами `english-cardbook:*`.
Сервера нет, аккаунт не нужен, данные не покидают компьютер.

Обратная сторона: чистка истории браузера стирает и словарь тоже. Поэтому
в настройках есть кнопка «Сохранить копию в файл» — она выгружает слова,
колоды, занятия и конспекты в один JSON, который можно положить куда угодно
и загрузить обратно на любом устройстве.

## Структура проекта

```
src/
  features/     возможности приложения, каждая в своей папке
    dictionary/   словарь: хранилище слов, форма, карточка
    decks/        колоды
    study/        карточки для заучивания
    quiz/         сборка теста
    grammar/      конспекты и редактор текста
    lessons/      журнал занятий
  pages/        страницы, по одной на раздел
  shared/
    lib/          хранилище, переводы, работа с датами и копиями
    types/        модели данных
    ui/           общие элементы интерфейса
  styles/       темы оформления
```
